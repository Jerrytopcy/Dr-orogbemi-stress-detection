# University Job Stress Management System (StressDetect)

A comprehensive, scientifically-backed web application designed to assess, analyze, and manage job-related stress among academic and administrative staff in university environments.

## 📌 Project Overview
**StressDetect** provides a secure, anonymous platform for employees to evaluate their workplace stress levels using validated methodologies (based on the Perceived Stress Scale). It not only offers immediate, personalized feedback to the individual user but also aggregates anonymous data to help organizational leaders identify systemic issues and improve the overall workplace environment.

## ✨ Key Features
- **Scientific Assessment:** Utilizes a detailed questionnaire to accurately evaluate stress levels across various organizational dimensions (Workload, Infrastructure, Culture, etc.).
- **Instant Insights & Recommendations:** Provides users with immediate personal and organizational recommendations based on their specific stress profile.
- **Interactive Dashboards:** Visualizes stress trends and distributions using beautiful, interactive charts (powered by Chart.js).
- **Secure & Anonymous:** No personal identifiable information is required. Access is managed via secure, one-time-use cryptographic tokens to ensure data integrity and confidentiality.
- **Aggregate Admin Analytics:** Advanced computation of overall organizational stress data, identifying the most challenging root causes across the institution.
- **Exportable Reports:** Generates comprehensive PDF reports of assessment history and aggregate data.
- **Modern UI/UX:** Responsive, accessible design with dark mode support and smooth micro-animations.

## 🛠️ Technology Stack
### Frontend
- HTML5 & CSS3 (Custom responsive styling, Dark Mode)
- Vanilla JavaScript (DOM manipulation, State management)
- **Chart.js:** For rendering interactive data visualizations
- **jsPDF & AutoTable:** For generating downloadable PDF reports

### Backend
- **Node.js & Express.js:** Robust server architecture handling API requests
- **PostgreSQL:** Relational database for storing anonymous assessments and invitation tokens
- **bcryptjs & JSON Web Tokens (JWT):** For secure authentication and data protection

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- PostgreSQL database

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jerrytopcy/Dr-orogbemi-stress-detection.git
   cd Dr-orogbemi-stress-detection
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Create a `.env` file in the root directory and add the following variables:
   ```env
   PORT=3000
   DATABASE_URL=your_postgresql_connection_string
   ADMIN_SECRET_KEY=your_secure_admin_password
   APP_URL=http://localhost:3000
   ```

4. **Start the server:**
   ```bash
   npm start
   ```
   The application will be running at `http://localhost:3000`.

## 🔒 Security & Privacy
Participant privacy is the cornerstone of this system. 
- Assessments are completely unlinked from user identities.
- System access is controlled via single-use token links generated by administrators.
- Database connections use SSL in production environments.
